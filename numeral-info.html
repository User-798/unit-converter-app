About Numeral Systems

Numeral systems are different ways to represent numbers. The converter supports:

  • Decimal (Base 10): The standard number system using digits 0-9
  • Binary (Base 2): Uses only 0 and 1 (e.g., 1010 = decimal 10)
  • Octal (Base 8): Uses digits 0-7 (e.g., 12 = decimal 10)
  • Hexadecimal (Base 16): Uses digits 0-9 and letters A-F (e.g., A = decimal 10)

Enter a valid number in the source system to convert it to other numeral systems.
